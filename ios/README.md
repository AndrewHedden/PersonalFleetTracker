# iOS app

Native SwiftUI app for Stablebook. Scaffolded in Phase 4.

Will use:

- SwiftUI + Swift Concurrency
- AWS Amplify Swift SDK for Cognito sign-in and signed API calls
- Keychain for token storage
- XCTest for unit/UI tests
- Fastlane (later) for TestFlight deploys

This directory is intentionally not a pnpm workspace.
